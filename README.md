Power BI automatically connects visuals on the same page, allowing them to interact with one another. This can be seen on the Operations page of the Power BI training, where selecting a specific driver name in the table automatically updates the map to reflect that driver’s location. In previous Flex assignments, multiple steps were required in Tableau to connect visuals so they would filter one another. In the future, Power BI may be more beneficial than Tableau for situations where visual interaction and filtering are important.

One number I calculated by hand in Flex 3 was Net Contribution, which I calculated in Excel by subtracting Cost to Serve, based on the customer's tier, from Profit for each row. I would build this as a calculated column in Power BI because Net Contribution is a fixed value for each individual row, with each row having its own Profit and Cost to Serve. If Net Contribution lives in the Power BI model instead of only in my Excel workbook, Anita and Marcus can filter and analyze the column by factors such as customer tier while using the same calculation. This gives Anita and Marcus a consistent number they can access during a meeting without having to ask me to manually recalculate or update the Excel file.
